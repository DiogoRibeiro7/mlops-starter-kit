# Example Dataset

`raw/example.csv` is a synthetic binary classification fixture created for
this repository. It contains 24 rows, two numeric features and a `target`
column. It is distributed under the repository's MIT license.

The classes are intentionally separable so the complete workflow runs quickly.
Scores on this fixture demonstrate plumbing, not real-world model quality.
Use an independent evaluation dataset and domain-specific validation before
setting promotion thresholds for real projects. Do not commit private data.
