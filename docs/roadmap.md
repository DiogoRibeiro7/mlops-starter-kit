# Roadmap

## Available

- Typed configuration and numeric classification workflows using real libraries.
- Local model snapshots, integrity checks, promotion gates and rollback history.
- Structured run records, batch prediction and a validated prediction API.
- Cross-platform tests, coverage enforcement, wheel and container validation.

## Next Integrations

- A managed model registry and remote experiment tracking adapter.
- Domain-specific preprocessing pipelines and time-aware validation examples.
- Monitoring, drift detection and retraining policies tied to evaluation data.
- Object storage with portable artifact references and retention rules.
- Authenticated deployments and approval-protected package publication.

Choose integrations for a concrete deployment need and include contract tests
for each adapter. The local implementation remains useful for learning and
bootstrapping projects without cloud credentials.
